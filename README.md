# 🌭 Woofdoku

A cute logic puzzle (Queens / "Meowdoku" style), but with dachshunds. The game is a single self-contained `index.html` with no build step and no dependencies.

**Play:** https://johanso-au.github.io/Woofdoku/

## Rules
- 8×8 grid split into 8 coloured territories.
- Exactly one dog per row, per column and per territory.
- Dogs can't touch each other, not even diagonally.
- Tap / left-click marks ✕. Drag to mark many squares (drag from an ✕ to erase). Double-tap / right-click places a dog.
- A wrong dog costs a ❤. You have 3.

## Features
- **50 levels** in five tiers (Puppy, Easy, Medium, Tricky, Expert). Difficulty rises steadily: early levels start with a one-square territory, and later ones need "what if" and pair deductions.
- Every level has exactly one solution, and you can reach it by logic alone. The opening move is always findable.
- **Hints** work from your current board. They show the next logical step on the grid (the area involved, the squares it blocks, a "ghost" dog for what-if reasoning) and explain why it works.
- **Scoring:** level bonus + speed (vs. par) + tidiness (fewer ✕ marks; none at all is a big bonus) + hearts left − hints. 1–3 stars per level, and a local high-score table.
- **19 badges**, e.g. Speedy Sausage (under a minute), Clean Paws (no ✕s), Lucky Guess, Hot Dog Streak, Night Owl.

Progress is saved in the browser (localStorage).

## Rebuilding the levels
The levels are generated by the game's own generator and embedded in `index.html`:

```
node tools/build-levels.js
```

For each tier it generates a pool of puzzles. It keeps only those with a unique, logic-only solution and a tier-appropriate opening, sorts them by solving effort, and writes an evenly-spaced ladder into the `LEVELS` block of `index.html`.
